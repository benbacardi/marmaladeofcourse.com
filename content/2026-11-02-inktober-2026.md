[Inktober](https://inktober.com/) is a drawing challenge that's been around for a while now that provides a single-word prompt for each day of October, with the intention to "focus on improving skill and developing positive drawing habits". This is the second year that I've done it, and although I've been posting my sketches on Mastodon each day, I've brought them all together in this post.
